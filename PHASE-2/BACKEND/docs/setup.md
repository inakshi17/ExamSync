# Setup Guide

1. Install Node.js and MongoDB (or create a free MongoDB Atlas cluster).
2. Open the PHASE-2/BACKEND folder in a terminal.
3. Run `npm install` to install dependencies.
4. Create a `.env` file, copying `.env.example`, and add your MongoDB link.
5. Run `node seed.js` to add starting data (optional).
6. Run `node server.js` to start the server.
