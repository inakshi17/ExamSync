# ExamSync Backend (Phase 2)

Backend for ExamSync, an exam management system built with Node.js, Express and MongoDB (Mongoose).

## Folders
- `config/` - database and app configuration
- `middleware/` - authentication middleware
- `models/` - Exam, ExamHall, Faculty, Seating, Student, UFM
- `routes/` - admin, auth, faculty and student routes

## Scripts
- `server.js` - starts the API server
- `seed.js` - fills the database with starting data
- `importStudents.js` - imports students from a CSV file

## Docs
See the `docs/` folder for setup, models, routes and guides.
