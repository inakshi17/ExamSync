# ExamSync -- Smart Examination Coordination Portal

## About

ExamSync is a C/C++ based examination system that automates the exam seating arrangement and facilitates the examination coordination using the concepts of Data Structures & Algorithms and Object Oriented Programming for a smart and automated system of examination hall seating arrangement.

## Objectives
Automate examination seating arrangement
Reduce the problems of seating arrangement and eliminate manual work
Provide students with their room and seat details
Manage faculty's invigilation duties
Generate seating plans and hall tickets
Maintain UFM records digitally

## Features
Smart and rule-based seat allocation
Student examination & seating details
Faculty invigilation duty management
Admin management module
Seating plan and hall-ticket generation
UFM record management

## Concepts Used

DSA in C:
Arrays
Linked Lists
Min-Heap / Priority Queue
Hashing
Searching
Quick Sort / Merge Sort

OOP in C++:
Classes & Objects
Encapsulation
Inheritance & Polymorphism
Constructors & Destructors
Operator Overloading
Exception Handling
File Handling
